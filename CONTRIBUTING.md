# Contributing

Thanks for helping improve Light Up.

## Local Setup

1. Install JDK 17.
2. Install Android Studio or Android SDK command-line tools.
3. Clone the repository.
4. Run `./gradlew assembleDebug` or `.\gradlew.bat assembleDebug`.

## Pull Requests

- Keep runtime behavior offline.
- Avoid adding third-party dependencies unless they solve a clear problem.
- Test alarm scheduling and ringing behavior on a physical phone when possible.
- Include screenshots or screen recordings for UI changes.
- Update `README.md` when setup or user-facing behavior changes.
